# Editor UX Fix

- **꾹 누르기(0.5초) = 그 줄 접기/펴기.** 접혀 있으면 펴고, 아니면 접는다. 자식이 없는 줄이면 그 줄을 품은 가장 가까운 위 줄(부모 항목, 제목)을 접는다. 누르는 동안 4px 넘게 움직이면 보통 드래그 선택이다.
- **캐럿이 있는 바로 그 자리를 클릭하면 그 줄을 접거나 편다.** 자식이 없는 줄이면 아무 일도 없다. 편집기에 포커스가 없을 때의 클릭(돌아오는 클릭)은 치지 않는다. 캐럿을 옮기지 않은 클릭 = 접기/펴기, 옮긴 클릭 = 캐럿 이동.
- **Alt+휠 = 마우스 자리의 형제들을 한 단계씩 펴기(위로)/접기(아래로).** 형제는 같은 부모 아래 같은 수준의 목록 항목(같은 들여쓰기)이나 제목(같은 수준)이다. 지금 상태에서, 펴기는 보이는 접힌 줄 중 가장 얕은 단계를, 접기는 보이는 펼친 줄 중 가장 깊은 단계를 모두 편다/접는다. 최상단 줄 위에서 굴리면 문서 전체가 대상이다.
- 캐럿을 옮기는 것만으로는 펴지지 않는다. 다만 캐럿이 숨은 내용 한가운데로 들어가면(검색 등) CodeMirror가 편다.
- 설정에서 각 동작(꾹 누르기, 캐럿 자리 클릭, Alt+휠)을 하나씩 끄고 켤 수 있다.
- 데스크톱 전용. 모바일은 지원하지 않는다.

## 설치

```
npm install
npm run build
```

`main.js`, `manifest.json`을 `<볼트>/.obsidian/plugins/editor-uxfix/`에 복사하고 설정 → 커뮤니티 플러그인에서 켠다.
옵시디언 설정의 "들여쓰기 접기"(Fold indent)와 "제목 접기"(Fold heading)가 켜져 있어야 접을 수 있다.
