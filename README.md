# Editor UX Fix

- **꾹 누르기(0.5초) = 부모 접기.** 그 줄을 품은 가장 가까운 위 줄(부모 항목, 제목)을 접는다. 부모가 없는 최상단 줄이면 그 줄을 접는다. 누르는 동안 4px 넘게 움직이면 보통 드래그 선택이다.
- **오른쪽 버튼 꾹 누르기(0.5초) = 그 줄과 형제 접기.** 같은 부모 아래 같은 수준의 목록 항목(같은 들여쓰기)이나 제목(같은 수준)을 자신까지 모두 접는다. 부모가 없으면 문서 전체에서 찾는다. 짧게 누르면 보통 메뉴가 뜬다. Windows 전용(macOS, Linux는 메뉴가 누르는 순간 떠서 잴 수 없다).
- **캐럿이 접힌 줄이나 그 자식으로 들어가면 펴진다.** 화살표로 그 줄에 오거나 그 줄을 클릭하면 펴진다. `…` 오른쪽을 클릭해도 펴진다. 캐럿이 자식에 놓이면 어떻게 왔든(화살표, 검색, 이동 명령) 펴진다. 범위 선택(Shift) 중에는 펴지 않는다.
- **캐럿이 있는 바로 그 자리를 클릭하면 그 줄을 접거나 편다.** 자식이 없는 줄이면 아무 일도 없다. 편집기에 포커스가 없을 때의 클릭(돌아오는 클릭)은 치지 않는다. 캐럿을 옮기지 않은 클릭 = 접기/펴기, 옮긴 클릭 = 캐럿 이동.
- 접힌 줄을 꾹 누르면 누르는 순간 펴지고, 부모가 있으면 부모를 접는다. 최상단이면 펴진 채로 둔다.
- 설정에서 각 동작(꾹 누르기, 오른쪽 꾹 누르기, 캐럿 자리 클릭, 캐럿이 들어가면 펴기)을 하나씩 끄고 켤 수 있다.
- 데스크톱 전용. 모바일은 지원하지 않는다.

## 설치

```
npm install
npm run build
```

`main.js`, `manifest.json`을 `<볼트>/.obsidian/plugins/editor-uxfix/`에 복사하고 설정 → 커뮤니티 플러그인에서 켠다.
옵시디언 설정의 "들여쓰기 접기"(Fold indent)와 "제목 접기"(Fold heading)가 켜져 있어야 접을 수 있다.
